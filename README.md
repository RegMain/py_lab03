# Лабораторная работа №3

**Задача**: написать пакет с моделью медиа (аудио, видео) и катологом объектов

**Модель объекта**: `catalog.models.MediaObject`
Содержит:
- уникальный идентификатор (`str`)
- категория (фильм / музыка / etc) (`str`)
- название (`str`)
- жанр (`str`)
- автор (`str`)
- длительность в мс (`int`)
- размер в байтах (`int`)
- год выпуска (`int`)
Создана через `@dataclass` с последующими проверками на корректность через метод `__post__init__`

**Каталог**: `catalog.models.MediaCatalog`
Функционал:
- добавление
- получение по идентификатору
- удаление по идентификатору
- нахождение по категории (происходит за линейное время от количества вхождений категории ценой ценой увеличения расхода памяти) - возвращает список id объектов из данной категории
- нахождение по имени (происходит за линейное время от количества вхождения имени ценой увеличения расхода памяти) - возвращает список id объектов с данным названием
- нахождение количества объектов в каталоге
- итерирование по каталогу в порядке добавления объектов в каталог (так же, как итерирование по `dict` в Python 3.7+)
- проверка на нахождение объекта в каталоге
- сохранение каталога в JSON
- загрузка каталога из JSON

**Инструкция**: установите пакет (требуется версия Python 3.10 и новее) и импортируйте MediaCatalog и MediaObject из пакета в своё решение. При желании вы можете использовать CLI-демонстрацию работы через `python -m catalog` (при запуске через виртуальное окружение).

**Выводы**:
- необходимо быть аккуратным при работе с данными и учитывать случаи несовпадения типов
- при возврате из функции mutable значения нужно не забывать копировать данные, если они используются самим объектом
- при работе с собственными структурами данных нужно продумывать все возможные ошибки :)
